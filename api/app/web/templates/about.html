? radovan

Radovan is a meta search engine for books and articles, focused on open-access scientific literature.

The results inherit the order in which they are displayed at the source (original page or api) and are grouped per provider.

Ideally, as much metadata as possible is preserved from the origins, but that is not always possible. Not all sources provide the same quantity/quality of metadata. In the end the priority is to get links, get texts, get reading.

Link classification is only somewhat reliable atm. In theory

  • full text links should trigger a direct download of a pdf, epub file or take you to a website with a full accessible html version;
  • landing page links should take you to a page where you can find links to the source, along with a metadata;
  • unknowns are known to be unknown.

In the top right corner of each provider block there is a userful url, which you can use to inspect the results of your query directly on a providers website.

? api

Radovan has a simple api, now at version 2.0. Better documentation is still on the way.

Search is executed in two steps. A GET request to the search endpoint starts a search job and returns the job id. You can then use this job_id to poll the search_status endpoint, which either returns the current status of the job or the aggregated results in json or html (default).

trigger search

endpoint:
/api/search

query parameters:
author, title, year, isbn, doi, sources, format, request_timeout

sample query:
/api/search?author=haraway&title=cyborg&year=&isbn=&doi=&sources=0&sources=1&sources=3&format=json&request_timeout=15

pool results

endpoint:
/api/search-job

path parameters:
job_id

query parameters:
format

sample query:
/api/search_job/?format=html

get providers

You can query the api to get a dictionary of current sources and their ids:
/api/sources

? code

The code is hosted on codeberg.

It's easy to get your own instance up and running with docker compose. It's licensed under GPLv3.

? issues

Radovan is a relatively stable individual, but they've been through a lot of changes recently, so issues are to be expected. Report them here.

The queries should take no longer than 10 seconds. If they do something has gone wrong. Some providers are much slower than others.

? roadmap

Further development is planned, aside from adding more providers:

  • improve link classification;
  • improve metadata parsing and add export options;
  • possibly return results as they come in;
  • provider uptime motintoring.

? privacy

The server logs anonymised IPs to count trafic. Errors are logged without using and identifiable information.

? attribution

Radovan is a character from a comic book created by Matjaž Schmidt in the 1980s. In that story Radovan from planet Beta is a researcher from outer space interested in - out of all things and creatures - Earthlings.

On his visit back in the day he was appaled by our attitude towards the environment, which he desparately tried to adjust. You can see how that is going.

His first thought was that maybe we just lack the right information. So he tried to have a look at out research outputs, but couldn't even get access to it. Everything was paywalled or in a bzillion different places.

So he called on his distant cousin Radovan from planet Meta to sort this mess out. It only took him 40 years to come over. Distant cousin indeed.
